Go/Chrome/native controls on macOS with Rig 0.7.18, Codex 0.169.0 and Node 24.
The native account stays in place. This is a private loopback auth-none browser
qualification, with no host reboot or installed-service claim.

read-only/on-request project configuration, and submits no model turn during

public HTTP 202 response. The UI continues to report an unknown outcome.

alive, survivor reattachment without native Resume, owned CLI loss plus explicit
